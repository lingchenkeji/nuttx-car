## 🔴 发送功率相关（影响读卡器→卡片的距离）

### 1. **GsNReg (0x27) - N-driver 电导率**
- **当前值**: `0xFF` (最大)
- **作用**: 控制N-driver（NMOS）的电导率，影响TX1/TX2的输出功率
- **影响距离**: ⬆️ 值越大 → 输出功率越大 → 卡片能接收到的能量越多 → 距离越远
- **范围**: `0x00` ~ `0xFF` (二进制加权)
- **注意**: 
  - 值越大，电流消耗越大
  - 在软件掉电模式下最高位被强制为1
  - 只有在TX1和TX2开启时才有效

### 2. **CWGsPReg (0x28) - P-driver 非调制时电导率**
- **当前值**: `0x3F` (最大)
- **作用**: 控制P-driver（PMOS）在非调制期间的电导率
- **影响距离**: ⬆️ 值越大 → 载波功率越大 → 卡片获得的能量越多 → 距离越远
- **范围**: `0x00` ~ `0x3F` (6位，二进制加权)
- **注意**: 影响载波（连续波）的功率，决定卡片能否被激活

### 3. **ModGsPReg (0x29) - P-driver 调制时电导率**
- **当前值**: `0x3F` (最大)
- **作用**: 控制P-driver在调制期间的电导率
- **影响距离**: ⬆️ 值越大 → 调制深度越大 → 卡片能更清晰地解码信号
- **范围**: `0x00` ~ `0x3F` (6位，二进制加权)
- **注意**: 
  - 影响调制指数（调制深度）
  - 即使Force100ASK=1，ModGsP的值仍然有效
  - 调制深度影响卡片对命令的解码能力

### 4. **TxControlReg (0x14) - 发送控制**
- **当前值**: `0x43`
  - bit6=1: InvTx1RFOn (TX1反相，用于差分输出)
  - bit1=1: Tx2RFEn (使能TX2)
  - bit0=1: Tx1RFEn (使能TX1)
- **作用**: 控制TX1和TX2的使能和相位
- **影响距离**: 
  - ✅ 差分输出（TX1和TX2反相）→ 输出功率最大
  - ❌ 单端输出 → 输出功率减半
- **注意**: 必须同时使能TX1和TX2，并设置TX1反相，才能获得最大输出功率

## 🟢 接收灵敏度相关（影响卡片→读卡器的距离）

### 5. **RFCfgReg (0x26) - 接收增益配置** ⭐ **最重要**
- **当前值**: `0x70` (48dB，最高增益)
- **作用**: 控制接收器的放大增益
- **影响距离**: ⬆️ 增益越大 → 能检测到更弱的信号 → 距离越远
- **范围**: 
  - `0x30` = 30dB (近距离，防止过载)
  - `0x40` = 33dB
  - `0x50` = 38dB (中距离)
  - `0x60` = 43dB
  - `0x70` = 48dB (远距离，最高)
- **权衡**:
  - ✅ 高增益：远距离识别能力强
  - ❌ 高增益：近距离可能过载，无法识别
  - 💡 **建议**: 根据应用场景选择，或实现自适应增益

### 6. **RxThresholdReg (0x18) - 接收阈值**
- **当前值**: `0x64`
  - MinLevel = 6 (bit7:4)
  - CollLevel = 4 (bit3:0)
- **作用**: 设置位解码器的最小信号电平阈值
- **影响距离**: 
  - ⬇️ 阈值越低 → 能检测到更弱的信号 → 距离越远
  - ⬆️ 阈值越高 → 过滤噪声，但可能丢失弱信号
- **范围**: 
  - MinLevel: 0-15 (位7:4)
  - CollLevel: 0-15 (位3:0)
- **权衡**:
  - ✅ 低阈值：灵敏度高，但可能误触发
  - ❌ 高阈值：稳定性好，但可能丢失弱信号

### 7. **DemodReg (0x19) - 解调器设置**
- **当前值**: `0x4D` (复位默认值)
- **作用**: 控制解调器的内部参数
- **影响距离**: 影响信号解调质量，间接影响识别距离
- **注意**: 通常使用默认值，除非有特殊需求

### 8. **RxSelReg (0x17) - 接收器选择**
- **当前值**: `0x84`
  - UARTSel = 10 (内部模拟信号)
- **作用**: 选择接收器的信号源
- **影响距离**: 影响接收信号的质量
- **注意**: 通常使用默认值

## 🟡 调制解调相关（影响信号质量）

### 9. **ModWidthReg (0x24) - 调制宽度**
- **当前值**: `0x26`
- **作用**: 控制ASK调制的脉冲宽度
- **影响距离**: 
  - 影响调制深度和信号质量
  - 必须符合ISO14443A标准（约2-3µs）
- **范围**: `0x00` ~ `0xFF`
- **注意**: 通常使用标准值，不建议随意修改

### 10. **TxASKReg (0x15) - 发送ASK调制设置**
- **当前值**: `0x40`
  - bit6=1: Force100ASK (强制100% ASK调制)
- **作用**: 控制ASK调制的深度
- **影响距离**: 
  - 100% ASK → 调制深度最大 → 卡片解码更容易
  - 降低ASK → 可能影响卡片解码能力
- **注意**: ISO14443A要求100% ASK，必须设置为0x40

### 11. **TxSelReg (0x16) - 发送信号源选择**
- **当前值**: `0x10`
  - DriverSel = 01 (调制包络)
- **作用**: 选择发送器的内部信号源
- **影响距离**: 影响发送信号的质量
- **注意**: 通常使用默认值

## 🔵 其他影响参数

### 12. **TxModeReg (0x12) - 发送数据速率**
- **当前值**: `0x00` (106kbps)
- **作用**: 控制发送数据速率和编码方式
- **影响距离**: 
  - 106kbps是ISO14443A标准速率
  - 速率越低，信号越稳定，但传输时间越长
- **注意**: 必须与卡片支持的速率匹配

### 13. **RxModeReg (0x13) - 接收数据速率**
- **当前值**: `0x00` (106kbps)
- **作用**: 控制接收数据速率
- **影响距离**: 必须与发送速率匹配
- **注意**: 通常与TxModeReg相同

### 14. **ModeReg (0x11) - 模式寄存器**
- **当前值**: `0x3F`
  - TxWaitRF=1: 等待RF场稳定
  - CRCPreset=11: ISO14443A CRC预设值
- **作用**: 控制通信模式和CRC设置
- **影响距离**: 间接影响，确保正确的通信协议

### 15. **Reserved Registers (0x23, 0x25) - 保留寄存器**
- **当前值**: `0x88`, `0x87` (复位默认值)
- **作用**: CV520特定的模拟配置
- **影响距离**: 可能影响模拟电路性能
- **注意**: 使用数据手册推荐的默认值

## 📊 参数优先级（对距离影响）

### 🔴 **高优先级**（直接影响距离）
1. **RFCfgReg** - 接收增益 ⭐⭐⭐⭐⭐

3. **CWGsPReg** - P-driver载波电导率 ⭐⭐⭐⭐

## 💡 优化建议

### 场景1: **最大识别距离**
```
RFCfgReg = 0x70 (48dB)
GsNReg = 0xFF (最大)
CWGsPReg = 0x3F (最大)
ModGsPReg = 0x3F (最大)
RxThresholdReg = 0x64 (较低阈值)
```

### 场景2: **近距离稳定识别**
```
RFCfgReg = 0x30 (30dB) 或 0x40 (33dB)
GsNReg = 0xFF (保持最大)
CWGsPReg = 0x3F (保持最大)
ModGsPReg = 0x3F (保持最大)
RxThresholdReg = 0x84 (较高阈值，过滤噪声)
```

### 场景3: **兼顾远近（折中）**
```
RFCfgReg = 0x50 (38dB)
GsNReg = 0xFF
CWGsPReg = 0x3F
ModGsPReg = 0x3F
RxThresholdReg = 0x74 (中等阈值)
```

## ⚠️ 注意事项

1. **功率限制**: 提高发送功率会增加电流消耗和发热
2. **过载问题**: 高增益在近距离可能导致接收器饱和
3. **标准合规**: 某些参数必须符合ISO14443A标准，不能随意修改
4. **天线匹配**: 识别距离还受天线设计和匹配电路影响
5. **环境因素**: 金属干扰、温度等也会影响识别距离

---

## 🔧 调试步骤

1. **先调整接收增益** (RFCfgReg) - 影响最大
2. **再调整接收阈值** (RxThresholdReg) - 微调灵敏度
3. **最后调整发送功率** (GsN/CWGsP/ModGsP) - 如果接收已优化但距离仍不够

## 📝 实际测试配置记录

### 配置1: **大线圈 - 全距离覆盖（0-40mm）** ✅ **推荐配置**

**硬件条件**: 大线圈（线圈尺寸较大，具体尺寸待补充）

**软件配置**:
```
RFCfgReg      = 0x40 (33dB)        // 接收增益
RxThresholdReg = 0x64 (MinLevel=6)  // 接收阈值
GsNReg        = 0xFF (最大)         // N-driver电导率
CWGsPReg      = 0x3F (最大)         // P-driver载波电导率
ModGsPReg     = 0x3F (最大)         // P-driver调制电导率
TxControlReg  = 0x43 (差分输出)     // TX1+TX2反相
```

**测试结果**:
- ✅ **识别距离**: 0-40mm（全覆盖，无盲区）
- ✅ **近距离**: 0-10mm 稳定识别（无过载）
- ✅ **中距离**: 10-30mm 稳定识别
- ✅ **远距离**: 30-40mm 稳定识别
- ✅ **成功率**: 高（具体百分比待补充）

**关键发现**:
1. **大线圈的优势**: 
   - 更大的线圈面积 → 更强的磁场耦合
   - 更好的阻抗匹配 → 更高的功率传输效率
   - 减少近场盲区 → 即使33dB增益也不会过载

2. **33dB增益 + 阈值6的组合**:
   - 低增益避免了近距离过载
   - 低阈值提高了远距离灵敏度
   - 大线圈补偿了增益降低带来的距离损失

3. **硬件vs软件**:
   - 大线圈（硬件优化）比单纯提高增益（软件）更有效
   - 硬件优化可以同时解决近距离过载和远距离识别问题

**适用场景**: 
- 需要全距离覆盖（0-40mm）的应用
- 对识别距离要求不是特别极端（>50mm）的场景
- 需要稳定识别，无盲区的应用

**备注**: 
- 此配置在大线圈上测试通过
- 小线圈可能需要不同的增益配置
- 线圈尺寸和匹配电路对识别距离影响很大
